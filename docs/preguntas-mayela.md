## 1. Las claves oficiales de cada trámite (homoclaves)

**Qué es:** cada trámite ante la ATTRAPI tiene una clave oficial. Por ejemplo, en
el expediente de Bulkmatic el formato del Registro de Tarifas dice **ATTRAPI-03-005**.
Antes, con la Agencia Reguladora, esas claves empezaban con **ARTF-**.

**Para qué sirve:** el sistema pone la clave correcta en cada expediente y en los
escritos. Si la ATTRAPI cambia la clave o los requisitos, los expedientes viejos
conservan la versión con la que se abrieron.

**Qué necesito:** la clave actual (ATTRAPI-…) y, si la sabes, la anterior (ARTF-…) de:

| Trámite | Clave actual (ATTRAPI-…) | Clave anterior (ARTF-…) |
|---|---|---|
| Proyecto Ejecutivo | | |
| Permiso de servicios auxiliares | | |
| Constancia de Inicio de Operaciones | | |
| Registro de Tarifas | ATTRAPI-03-005 ✔ | |
| Programa de Contingencias | | |
| Pólizas de seguro | | |
| Aviso de cambios en la terminal | | |
| Renovación del permiso | | |

**Dónde están:** en la parte de arriba de cada formato de la ATTRAPI, o en la ficha
del trámite en el portal de la ATTRAPI / CONAMER.

## 3. El texto exacto de los endosos de las pólizas

**Qué es:** las frases que la ATTRAPI exige que vengan **palabra por palabra** en
las pólizas de seguro (por ejemplo, a quién se nombra beneficiario).

**Para qué sirve:** cuando una aseguradora como Berkley mande una póliza, el sistema
compara su texto con el oficial y marca cualquier palabra de más o de menos, antes
de que la ATTRAPI la observe.

**Qué necesito:** sube las **pólizas de KERI que la ATTRAPI ya aprobó**, o el
documento donde la ATTRAPI indica el texto de los endosos. Yo saco las frases y tú
confirmas.
